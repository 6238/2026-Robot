Guidance for any coding agent working in this repository.

For cold-start environment setup (JDK 17, `JAVA_HOME`, first Gradle build) on a generic machine, see [`AGENT_SETUP.md`](AGENT_SETUP.md).

## Branch naming

All branches: `<firstname>-<last-initial>/<dash-delimited-short-name>` (lowercase), e.g. `maxim-g/hopper-jam-fix`. See [`STYLEGUIDE.md`](STYLEGUIDE.md).

## Commands

```bash
# Build (also runs Spotless formatter automatically before compile)
./gradlew build

# Build without tests
./gradlew build -x test

# Run all tests
./gradlew test

# Run a single test class
./gradlew test --tests "subsystems.ShooterTest"

# Run a single test method
./gradlew test --tests "subsystems.ShooterTest.setFlywheelRPM_callsSetFlywheelSpeed"

# Deploy to robot
./gradlew deploy

# Run AdvantageKit log replay
./gradlew replayWatch

# Apply formatting manually (Spotless / Google Java Format)
./gradlew spotlessApply
```

On Windows, use `.\gradlew.bat` instead of `./gradlew`.

Spotless formatting is enforced automatically — it runs before every `compileJava`. Formatting uses Google Java Format. All `.java`, `.gradle`, `.json`, and `.md` files are formatted.

## Architecture

This is an FRC robot project for Team 6238 (2026 season) using **WPILib Command-based Java** with **AdvantageKit (AK)** for logging and replay.

### AdvantageKit IO Layer Pattern

Every hardware subsystem follows this pattern:
- `FooIO` — interface with a nested `@AutoLog FooIOInputs` class and default no-op methods
- `FooIOTalonFX` / `FooIOSim` / `FooIOPhotonVision` — concrete hardware/sim implementations
- `Foo` (subsystem) — holds a `FooIOInputsAutoLogged` (generated by AK annotation processor), calls `io.updateInputs(inputs)` in `periodic()`, then `Logger.processInputs()`

`FooIOInputsAutoLogged` is generated at build time from the `@AutoLog` annotation. Tests must interact with the auto-logged subclass but can cast to `FooIOInputs` in `doAnswer` lambdas.

### Runtime Mode

`Constants.currentMode` is `REAL` on hardware, otherwise `Constants.simMode` (set to `SIM` by default). `RobotContainer` switches on this enum to instantiate the correct IO implementations.

### Subsystems

- **Drive** — 4-module swerve using CTRE TalonFX + Phoenix 6. Odometry via `PhoenixOdometryThread`. Simulation via MapleSim (`MapleSimSwerve`). Exposes `align(APTarget, BooleanSupplier)` for teleop AutoPilot assistance.
- **Vision** — Multi-camera AprilTag pose estimation. Filters observations (zero tags, ambiguity > 0.07 single-tag, |Z| > 0.75 m, out-of-bounds). Computes std devs as `pow(distance, 2) / tagCount` × baseline × per-camera factor, then feeds `drive::addVisionMeasurement`.
- **Shooter** — Flywheel + feeder motors. `flywheelUpToSpeed()` checks `inputs.flywheelVelocity.isNear(target, tolerance)`. `setFlywheelVoltage()` clears `targetFlywheelVelocity` to zero.
- **Hopper** — Dual indexer (indexer + top indexer) feeding the shooter.
- **Intake** — Pivot + roller with jam detection (debounced stall current → reversal). Calls an `onJam` callback (used for controller rumble).
- **Superstructure** — State machine (`IDLE → SPINNING_UP → SHOOTING/PASSING`) coordinating Shooter, Hopper, Intake, and Drive heading.

### Navigation

- **Autonomous** — PathPlanner handles all auto paths. Named commands registered in `RobotContainer.configureNamedCommands()`.
- **Teleop assistance** — AutoPilot library (`com.github.therekrab:autopilot:1.5.0`). `AutomaticCommands` builds `APTarget`-based commands using `drive.align()`. B button = context-aware (trench/bump), D-pad = fixed targets (hub wall, wall scrape, under tower).

### Robot Identity

`RobotIdentity` selects between `COMPTunerConstants` and `PRACTICETunerConstants` based on the roboRIO serial number. Both live in `src/main/java/frc/robot/generated/`.

### Alerts

`AlertUtils.processCriticalAlert(alert, condition)` calls `criticalErrorRumbleFunction.run()` when `condition` is true. This field is set in `RobotContainer` but is `null` by default — **unit tests must never trigger it** (set `connected = true` in mock `updateInputs` doAnswer, or initialize HAL in `@BeforeAll`).

### Tests

Tests live in `src/test/java/subsystems/` (JUnit 5 + Mockito 5). The pattern:
1. Mock the `IO` interface (not the subsystem class)
2. Add a default `doAnswer` in `@BeforeEach` that sets all `*Connected` flags to `true` — prevents `Alert.set(true)` NPE and `criticalErrorRumbleFunction` NPE
3. Call `command.initialize()` to execute `runOnce`/`runEnd` commands without the CommandScheduler
4. Add `HAL.initialize(500, 0)` in `@BeforeAll` if the test exercises timing (debouncers via `SimHooks`) or `Alert.set(true)`

### Logs

AdvantageKit `.wpilog` files can be replayed with `./gradlew replayWatch` and inspected with AdvantageScope when available. Prefer project log tooling over ad-hoc binary parsing.
